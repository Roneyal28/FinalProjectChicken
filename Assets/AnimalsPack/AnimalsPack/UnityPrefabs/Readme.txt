
Notes
--------------------------------------------------------------------------------

* Engine Compatibility: These prefabs are designed exclusively for the Unity 
  engine.
* Dependencies: The "Sprites" folder must be included in your project for 
  these prefabs to function correctly.
* Functionality: Each prefab includes a basic movement script.
* Configuration: For detailed instructions on how to configure the script, 
  please refer to the AnimalBehaviour Guide PDF.
* Rendering: A custom material is included, fully compatible with both the 
  Universal Render Pipeline (URP) and the Built-in Render Pipeline.

Enjoy!
